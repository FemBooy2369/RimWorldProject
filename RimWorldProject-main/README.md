# 🎮 RimWorld Mod Manager
> Красивый и удобный менеджер модов для RimWorld на .NET MAUI

![Version](https://img.shields.io/badge/Version-3-neon)
![.NET MAUI](https://img.shields.io/badge/.NET%20MAUI-10.0-purple)

---

## ✨ Основные возможности

### 🔍 Поиск модов
- Поиск по **Steam Workshop** с реальными превью и описаниями
- История последних поисков (до 20 записей)
- Быстрые переходы на Steam и Nexus Mods

### ❤️ Избранное
- Сохранение любимых модов
- Удобное управление (удаление, открытие ссылок)
- Синхронизация с рекомендациями

### 📁 Мои моды
- Выбор папки с модами RimWorld
- Автоматическое чтение `About/About.xml`
- **Авто-теги** (Performance, QoL, Graphics, Overhaul и др.)
- **Быстрые фильтры по тегам** (чипы)
- Проверка совместимости с версией игры (1.5 / 1.6)
- Pull-to-Refresh

### 🌿 Vanilla Expanded
- Полный список модов из организации Vanilla-Expanded
- Загрузка с GitHub + **постепенное обогащение картинками и описаниями из Steam**
- Debounce-поиск
- Pull-to-Refresh
- Skeleton loading (красивые заглушки)

### 📊 Главная страница
- Дашборд со статистикой (Избранное / Мои моды / Найдено)
- Рекомендации модов на основе твоего избранного
- Неоновые анимации нажатий

## 🛠️ Стек технологий

- **.NET 10 + MAUI** (Windows / Android)
- MVVM архитектура
- Steam Web API + GitHub API
- Локальное хранение (JSON + Preferences)
- Неоновый UI + анимации

## 📁 Структура проекта
RimworldModManager/
├── Pages/              → Главные экраны
├── ViewModels/         → Логика и данные
├── Services/           → SteamApi, Github, Theme, ModFolder и др.
├── Converters/         → GreaterThanZero, InverseBool
├── Extensions/         → Неоновые анимации кнопок
└── Resources/          → Стили, цвета, иконки

## 🚀 Как запустить

1. Открой проект в **Visual Studio 2022/2026**
2. Вставь свой **Steam API ключ** в `SteamApiService.cs`
3. Запусти на **Windows** (рекомендуется)
